# My PHP Tutorial

This repository contains my practice code and notes for the PHP Tutorial assignment.

## Required Videos

- #1 - Why Learn PHP?
- #3 - Your First PHP File
- #4 - Variables & Constants
- #5 - Strings
- #6 - Numbers
- #7 - Arrays
- #8 - Multidimensional Arrays
- #9 - Loops
- #10 - Booleans & Comparisons

## Files

- `index.php` - Home page and links to exercises
- `03_first_php.php` - Basic PHP syntax and echo
- `04_variables_constants.php` - Variables and constants
- `05_strings.php` - Strings and string functions
- `06_numbers.php` - Numbers and arithmetic
- `07_arrays.php` - Indexed and associative arrays
- `08_multidimensional_arrays.php` - Multidimensional arrays
- `09_loops.php` - For, foreach and while loops
- `10_booleans_comparisons.php` - Booleans and comparison operators

## How to Run

1. Put the `my_php_tutorial` folder inside the XAMPP `htdocs` folder.
2. Start Apache in XAMPP.
3. Open a browser.
4. Go to:

   `http://localhost/my_php_tutorial/`

My learning notes are included as comments inside each PHP file.
